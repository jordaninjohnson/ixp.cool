# ixp.cool

Public landing page for **IXP** — an open-source digital signage and building communication platform being built in public.

## Current purpose

The site is intentionally a lightweight coming-soon page while the product is in its earliest engineering milestones.

It should:

- introduce IXP without overstating what exists
- make the project feel welcoming and interesting
- show the current engineering milestone
- point visitors toward the IXP GitHub organization
- evolve alongside real releases and real users

## Current project status

**Pre-v0.1 — Data Foundation**

The active technical work is focused on PostgreSQL, SQL, relational modeling, constraints, seed data, and reproducible database setup.
