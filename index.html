The idea

Build the boring parts well.

Digital signage is easy to demo and harder to operate. Real buildings introduce unreliable networks, replacement hardware, changing users, expired content, maintenance, and support handoffs. IXP is being designed for that reality.

01 / OPEN

Open from the core

The goal is useful open-source software that people can understand, run, inspect, improve, and eventually contribute to.

02 / OPERABLE

Built past the demo

Deployment, logs, health, backups, upgrades, and recovery belong in the product story — not in a forgotten checklist after launch.

03 / HUMAN

Made for real operators

Software should leave the next person with something understandable. Clear documentation and simple architecture are features.

Roadmap

One useful layer at a time.

The roadmap is intentionally small. Each release should leave behind working software, tests, documentation, and a clearer understanding of the system.

Now building

v0.1 — Data Foundation

The first release is focused on the relational model: organizations, buildings, locations, screens, devices, content, playlists, schedules, users, roles, and device health history.

The current technical focus is deliberately narrow: PostgreSQL, SQL, constraints, relationships, seed data, and reproducible database setup.
